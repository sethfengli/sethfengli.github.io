## 蜡烛难题

你利用了所有的条件条件吗？

“蜡烛难题”，这是由一位名叫顿克的心理学家中1945年想出来的。顿克这个实验，被广泛的应用在各类行为科学的研究中。

实验是这样的：工作人员带你进入一个房间，给你一支蜡烛、一盒图钉和几根火柴。然后跟你说：“请你把蜡烛固定在墙上点燃，但是腊油不可滴在桌上。”

你会怎么做？自己试试看。
