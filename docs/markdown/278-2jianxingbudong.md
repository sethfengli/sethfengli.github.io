动者，名之为尘；以不住者，名之为客。汝观阿难头自动摇，见无所动；又汝观我，手自开合，见无舒卷。】于是，佛普告大众：“若是众生，以摇动者，名之为尘；以不住者，名之为客。你们看见阿难头自动摇，而你们的见并无所动；你们又看见我的手自开合，而你们的见并无舒卷。”【云何汝今，以动为身？以动为境？从始洎终，念念生灭，遗失真性，颠倒行事。性心失真，认物为己，轮回是中，自取流转。】为什么你们至今还要以动的（生老病死）为身呢？以动的（成住坏空）为境呢？于是从始至终，时时刻刻妄念纷飞（念念生灭），而遗失真性（这湛寂不动的真性才是你自己），颠倒行事（妄认五蕴身心为己，喧嚣尘境为真）。性心失真（真心转化成妄心），把肉体当成自己的身、六尘缘影当成自己的心，因而在轮回中自取流转。〔从始洎终〕从始到终。洎（jì）：到，及。〔五蕴〕色蕴、受蕴、想蕴、行蕴、识蕴，这是构成身心的五大要素。其中色蕴构成身，其余四蕴构成心。〔性心〕真心。〔认物为己〕把肉体当成自己的身，六尘缘影当成自己的心。《圆觉经》云：“云何无明？善男子！一切众生从无始来，种种颠倒，犹如迷人四方易处，妄认四大为自身相，六尘缘影为自心相。譬彼病目，见空中华及第二月。善男子！空实无华，病者妄执，由妄执故，非唯惑此虚空自性，亦复迷彼实华生处。由此妄有，轮转生死，故名无明。”（注释详见《圆觉经精解》）〔四大〕地大、水大、火大、风大。地以坚硬为性，水以潮湿为性，火以温暖为性，风以流动为性。世间的一切有形物质，都有坚、湿、暖、动之四性，故称为“大”。这里的四大是指身体。〔六尘缘影〕六根缘六尘所产生的种种念想，而这些念想都是虚幻不实的，所以称之为六尘缘影——缘六尘之幻影。参考阅读：见性是心见性不灭 ## 见性不动

> 【尔时世尊，舒兜罗绵网相光手，开五轮指，诲敕阿难，及诸大众：我初成道，于鹿园中，为阿若多五比丘等，及汝四众言：一切众生不成菩提，及阿罗汉；皆由客尘烦恼所误。汝等当时，因何开悟，今成圣果？】

这时，憍陈如（憍陈那）起立白佛：“我现在是长老，于大众中独得解名，是因为悟“客、尘”二字证果。世尊！譬如旅客，投寄旅店，或住宿或餐食；住宿、餐食之事完毕，便整理行装前行，无暇安住。如果他真是店主，自然就不会整装前行。于是我就这样思惟：不住名为客，住者名为主人。客的含义，就是往来。又如天空放晴时，明亮的太阳升起，日光透过门窗的缝隙，照见空中的尘埃。这些尘埃摇动，而虚空寂然不动。我就这样思惟：澄寂名为虚空，摇动名尘埃。尘的含义，就是摇动。”佛印证说道：“是这样的。”
